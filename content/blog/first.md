# Music City Rust Developers Website Go-Live

## What is this?

We finally did it. We have an official website that we can use to host articles and contributions from the Nashville Rust developer
community. I'd like to thank Steven from the BDK project for pushing for this to happen and I'd like to thank the greater Nashville developer
scene in general for being a great network of professionals. The site will likely look kind of rough at first because I'm using a barebones 
pre-generated CSS package like Skeleton or MVP.css. I'll slowly make the site look better and revamp it to be more ergonomic. 

To explain the site a bit, I'm using a static-site generator called Zola, hooked into github and Cloudflare Workers that serves the site 
and updates automatically. I might add some interactivity via HTMX or Datastar if the need arrises but I figure that the needs of this website
will need to be explored as we move our way into the future. 

## The Plan

This site will host a variety of articles by the members of our local rust group, event summaries and also some small bits of trivia/information
about rust development. I will try to keep the website updated at least on a monthly schedule, posting updates up to one week after that month's 
meetup.
